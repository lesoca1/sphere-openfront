# Sphere OpenFront

A browser prototype for a board game played on a floating Goldberg-style sphere.

The board starts with an icosahedron, subdivides each triangular face, then
dualizes that mesh: the 12 original icosahedron vertices become pentagons, and
the remaining vertices become hexagons. Drag the sphere to spin it.

## Run

```bash
npm install
npm run dev
```
